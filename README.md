# Steal a Verity!

Детская игра для Roblox в жанре «укради персонажа». Вместо брейнротов — **Verity** разных цветов, редкости и дохода.

## Как играть

1. На конвейере посередине едут Verity. Подойди и купи (кнопка **E**).
2. Купленный Verity встаёт на твою базу и приносит деньги каждую секунду.
3. Доход копится в **кассе** (зелёная плита на базе). Наступи на неё, чтобы забрать деньги.
4. Заходи на чужие базы и **укради** Verity (держи **E** 2 секунды). Беги с ним к себе!
5. Хозяин может **шлёпнуть** вора шлёпалкой (она в инвентаре): вор уронит добычу, и Verity вернётся хозяину.
6. Кнопка **🔒 Защитить базу** (слева на экране) закрывает ворота на 30 секунд.
7. Лишнего Verity можно **продать** (кнопка **F**) за половину цены.

## Запуск

Нужны [Rojo](https://rojo.space) и Roblox Studio.

```bash
aftman install            # установит Rojo (или поставь Rojo любым способом)
rojo build -o StealAVerity.rbxlx   # собрать файл места
# либо живая синхронизация:
rojo serve                # и нажми Connect в плагине Rojo в Studio
```

Перед публикацией в Studio:

- **Game Settings → Players → Maximum Players = 8** (на карте 8 баз).
- **Game Settings → Security → Enable Studio Access to API Services** — чтобы работало сохранение в Studio (сначала опубликуй место).
- В **Game Settings → Avatar** лучше выбрать R15.

## Структура

```
src/shared/   Config (баланс, список Verity), Format (числа $1.5K)
src/server/   Main, World (карта), Bases, Conveyor, Stealing, Combat, Data, VerityFactory, Remotes
src/client/   HUD (деньги, защита, уведомления), Prompts (кто что видит), Effects (радуга)
```

## Безопасность для детей

В игре нет собственного чата и платных покупок. Если добавишь Game Pass или случайные награды — проверь правила Roblox (шансы нужно показывать) и заполни анкету возрастного рейтинга.
